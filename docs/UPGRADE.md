## 决策记录（2026-08-30 全部拍板）

1. **前端痛点优先**：HUD 重叠排布、鼠标响应、120FPS、器匣装备名，最先修。
2. **布局 = 分区常量 + 重排**：新建 `src/render/view/layout.ts` 统一分区坐标与间距。
3. **器匣装备名 = 悬停提示卡**（名 + 效果 + 合成路径）。
4. **剑宗/龙渊循环内叠加判 bug 修掉**，由 M1 重平衡吸收（历史平衡数据在该行为下测出，修正后全局重测）。
5. **除错深度 = 前后端全面体检**（audit/bench/确定性/守恒重跑 + skills.ts 15 类技能补测试）。
6. **新增系统 = 主菜单 + 场景流、图鉴系统**。战绩统计、伤害曲线不做。
7. **对局体验 = 侦查对手阵容、准备暂停 + 投降**。全局倍速持久化不做（战斗内 1×/2×/4× 维持现状）。
8. **架构 = 场景化 + 拆模块**（覆盖层抽组件，GameScene 主场景目标 <800 行）。
9. **执行顺序 = 阶段 0→F→R→M1→M2→M3→M4→M5**，每阶段过验证门才前进。

## 当时执行纪律（历史）

- 调平衡一律走 `sim:sweep` / `sim:ab` 框架，不手改数据表。
- 动机制前先量化（平台期结论：极差 10.1% 为局部最优，数值层不可再压缩）。
- 内核保持无头 / 完全确定 / 资源守恒三契约；游戏逻辑禁 `Date.now` / `Math.random`。
- 文案规格口吻：每档效果自含绝对数值，禁「提升至 / 翻倍」等相对表述。
- 视觉守 ART_BIBLE：禁荧光蓝绿紫、紫禁用、全简体、文人案头宋画体系。
- **不加新手引导教程**（定死红线）。
