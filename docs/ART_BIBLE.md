> 本文件是全项目视觉的**唯一真源**。任何颜色、字体、圆角、间距、特效语言都必须来自此处。
> 代码镜像位于 `src/render/view/palette.ts` 与 `src/ui/kit.ts`，二者必须保持同步。
> **禁止在组件内硬编码十六进制色值** —— 那是风格漂移的开始。
>
> **裁决：夜宴（Night Feast）**—— 以样稿为准：

> **唯一例外是棋子**——样稿的"漆碟 + 楷字"只是棋子占位，游戏内棋子一律使用

## 〇、方向：夜宴 · 幽冥水墨（Night Feast）

深**夜蓝墨**底 + 米金宣高光 + 朱砂鎏金点缀。不做白纸文人画，不做高饱和西幻。

**本体系是低对比体系，它的美来自精度。** 全部判定依赖数字，不依赖手感：
- 底色是夜的蓝墨（`#050b13 → #1a2c42`），像一场大漆夜宴——棋盘是盘中漆，字是席上金。
- 全场只有一种热色：朱砂。它出现的地方 = 需要血液反应的地方。
- 冷色全部去饱和：友方是玉青、法术是夜蓝、盾是月白灰——没有荧光，没有紫。
- 金是旧金（`#b39660` 哑光带褐），高光是米金（`#e3cfa0`），不是亮黄。

## 一、世界观基调

- **舞台**：《九幽墨卷》夜宴。调性：肃杀、静谧、有分量。战斗是"落墨"，死亡是"化墨"。
- **情绪曲线**：准备阶段如观画（静、留白、冷光）；战斗阶段如泼墨（烈、饱和、震颤）；决赛圈收束为一点聚光。
- **术语白名单**：准备→**备战**；战斗→**交战**；稀有度五阶→**凡/灵/宝/仙/神**品；出售（朱文印件）。
- **全简体**。仪式感交给字距字号，不靠繁体。
- **空态文案公式**：一句案头语 = 此刻是什么 + 将来会有什么。禁写功能说明书。

### 2.1 夜墨 10 阶（背景与结构）

→ `INK.700 #122031` → `INK.650 #16283a` → `INK.600 #1a2c42` → `INK.500 #263a52`（结构描边）
→ `INK.400 #46596f` → `INK.300 #7e8b9b`（雾青淡墨）。

### 2.2 米金宣 6 阶（亮面与文字）

`PAPER.50 #f7e7c3`（cream）→ `PAPER.100 #f2ecdd`（主文字）→ `PAPER.200 #ece5d4`（正文）

### 2.3 语义色

| 色 | 深 | 主 | 亮 | 语义 |
|---|---|---|---|---|
| 朱砂 | `#6b2a1e` | `#c65a45` | `#e58a6f` | 敌方/危险/暴击（唯一热色） |
| 旧金 | `#6b582a` | `#b39660` | `#e3cfa0` | 稀有/结算/鎏金装饰（只承担价值语义） |
| 玉青 | `#33524a` | `#9ec4ae` | `#bfdacd` | 友方/治疗/安全 |
| 夜蓝 | `#2c3a55` | `#5a6f96` | `#8ea3c8` | 法术/技能 |
| 月白 | `#56616e` | `#8b98a8` | `#c2cdd6` | 环境/中立/护盾 |

- **热色条款**：朱砂是唯一的攻击语义色；旧金只承担价值语义（稀有、结算、装饰），两者不许互换。
- **紫色全域禁用（含特效/粒子/飘字）**；减益印记 = 夜蓝黛环。
- 月白色域上限 `#c2cdd6`，不得侵入亮蓝。

### 2.4 稀有度五阶（样稿逐值）

凡 `#7e8b9b` 雾灰 / 灵 `#9ec4ae` 玉青 / 宝 `#8ea3c8` 夜蓝 / 仙 `#cf9bae` 胭脂 / 神 `#e3cfa0` 米金。
稀有度识别 = 色 + 形（顶部刻线/描边）双通道。

### 2.5 阵营三通道编码

| 通道 | 我方（下） | 敌方（上） |
|---|---|---|
| **色** | 玉青 `#9ec4ae` | 朱砂 `#c65a45` |
| **形** | 界格方肩剪影、六边底座 | 圭角尖肩剪影 |
| **位** | 屏幕下半 | 屏幕上半 + 敌营纱幕 |

判据：**去色截图下仍可按形状/位置通道判定任意单位归属。**

### 2.6 棋子身份色相 · 七族制

64 名棋子各带 `hue`，在墨体中只掺 32%。同族内任意两卡 hue 相距 ≥ 18° 或明度差 ≥ 0.12。

## 三、字体层级

| 层级 | 字体栈 | 用途 |
|---|---|---|
| **篆**（XiaoZhuan 子集） | `XiaoZhuan` → 楷体回退（`traitIcons.cssFamily`） | 羁绊徽章篆字——钟鼎的字 |
| **楷**（FONT.kai） | `Kaiti SC, STKaiti, KaiTi, Songti SC, serif` | 品牌、菜单标题、印文——书写的字 |
| **金石标题**（FONT.title） | `Songti SC, STZhongsong, Noto Serif SC, SimSun, serif`（+3px 字距） | 面板头、阶段条、按钮、结算 |
| **正文**（FONT.body） | `Songti SC, STSong, Noto Serif SC, SimSun, serif` | 描述、列表 |
| **数值**（FONT.num） | `Georgia, Songti SC, SimSun, serif` | 伤害飘字、等宽数值 |
| **仪器**（FONT.mono） | `SF Mono, Menlo, Consolas, monospace` | 顶栏数值、倒计时、英文微标 |

规则：标题 +3px 字距、正文 +1px；所有文本经 `main.ts` 注入 2× 分辨率，抗 DPI 发虚。
篆体为打包子集（`src/assets/fonts/seal.woff2`，22 字 6.7KB，源 TTF 与再生脚本见
`design/fonts/`），载入失败自动落楷体。

**有效字号政策**：与夜宴样稿的高密度编排
（样稿自身即用 9~10px 小注）冲突，分级执行：
- **阅读型中文文本**（描述/列表/记事/战报/详情卡/奇遇卡正文）下限 **13px**；
- **商品卡副文**（品阶·羁绊·价签行）下限 **12px**（居中截断防溢出）；
- **标签与小注**（mono 数值注/签条/帽行/快捷键脚注）下限 **11px**；
  **英文微标**（NIGHT FEAST / 导航英文）为装饰语汇，10px 起保留样稿气质。
  信息密度不够时改布局，不为凑数放大。

## 四、图标语言

- **羁绊图标**：小篆单字徽章（17 字全独特：丹鼎取「鼎」、丹师取「丹」消歧）。
  未激活灰环灰字；激活 N 档亮 N 圈金线（三档羁绊第三级三圈），纸白篆字。
  汉字即图标，几何与状态规格见 9.8。
- **通用图标**：线稿 + 1.5px 描边，几何闭合，禁止渐变填充。
- **状态图标**：色环 + 汉字，不用象形小图标。

## 五、材质语言

全部启动时烘焙（`textures.ts` + `bake.ts`），运行期零开销。宣纸纤维 / 墨点晕染 / 灵光 /
法环 / 火星拖尾 / 斩击弧 / 暗角。禁止：纯色方块、硬边圆滥用、Emoji、拉伸位图。

**全窗背景（index.html `#bg`）**：夜色山海——夜空渐变、46 星、月晕（不见月轮）+ 云絮、
三层虚化远山、雾带、70 金尘、涟漪、纸纹颗粒（overlay 5%）、暗角。
**滤镜全部在启动/resize 时一次性烘焙**进静态画布；逐帧只画星/尘/涟漪（无滤镜、无全屏渐变）。
Phaser 画布透明，场景内不再铺底色。

粒子预算：同屏 ≤ 220 粒（决赛余烬档 ≤ 320）；全屏覆层 ≤ 2 层。

## 六、棋子表现规范（AI 立绘 · 程序化合成）

棋子美术为 **AI 生成立绘**。源图 64 张：透明底 PNG，命名即棋子代号，
位于 `src/render/art/piece/ai/<defId>.png`（由 `scripts/slice-sheet.mjs` 自 8×8 原图
`design/pieces/sheet-8x8.png` 切分入库）。启动时 `preloadAiPieces()` 预解码，
烘焙期 `drawAiPiece()` 按源图**原生分辨率**落位到 208×208 纹理（脚底锚 (104, 184)），
烘焙期零重采样；缺图棋子回退程序化剪影（`silhouettes.ts`），任何棋子必有图。

### 6.1 合成规则（烘焙期程序派生，源图不携带）

1. **原生落位**：源内容（约 150px 高）原样入画布，不缩放；显示端按内容高归一
   （`silContentScale`），棋盘采样恰为 1:1 设备像素，清晰度上限即源图上限（不超分）。
2. **星级描边**：1★ 无描边；2★ 银色（`MOON.light`）；3★ 金色（`GILT.light`）。
   柔光沿轮廓三遍叠浓度，alpha 0.85，blur 随内容尺寸等比（12px 体量基准下约 5/6）。
3. **墨兽**：整体罩染青黛（rgba(58,86,134,0.38)，source-atop），复用玩家棋子立绘。
4. **敌我归属**：由血条颜色承担 —— 我方玉青恒色（低血不变色），敌方朱砂、残血提亮。
   描边不携带阵营语义。
5. **棋盘体量**（`UnitView`，格 72px）：内容高归一口径 68 逻辑 px，按"身体"量取
   （星级描边柔光不计入内容包围盒，归一不被光晕稀释）——
   1★ 61.2（85% 格）、2★ 69.4（96%）、3★ 78.9（110%，顶部轻微越格属预期体量）；
   宽体宽度收口 55。血条与菱星锚在内容顶上方 9px，随星级联动。
   备战/图鉴肖像内容高 0.72 格宽，商店卡 62px。

**样稿纪律**：凡立绘可以出现的地方（商店卡、棋盘、备战席、图鉴），一律用立绘，
不得用圆碟或文字代位。

### 6.2 星级晋升

| 星级 | 描边 | 体量 | 标记 |
|---|---|---|---|
| 1★ | 无 | ×0.90 | 一颗菱星 |
| 2★ | 银 | ×1.02 | 两颗菱星 |
| 3★ | 金 | ×1.16 | 三颗菱星 + 界格断环星冠（四段弧 + 四枚旋转方胜印 + 顶心主印） |

### 6.3 战斗动画

- 攻击：前摇（反向压 0.4 单位）→ 前冲 1.6 单位 → `Back.easeOut` 170ms 回弹；前摇 = 攻速 × 0.38。
- 受击：白闪 140ms + 3.5px 位移 + 冲击环 + 墨点。
- 死亡：墨迹溶解——420ms 渐隐 + 下坠 + 倾覆 16° + 缩放 0.82。
- 移动：格间插值 + 待机呼吸（错相正弦）。

## 七、技能特效语言

三原则：**读得懂 → 看得爽 → 不糊屏**。

### 7.1 四段式结构

```
蓄力预兆 → 释放主体 → 命中反馈 → 余韵消散
  0.35s      ≤0.2s      ≤0.1s      0.3~0.5s
```

### 7.2 几何语义表

| 语义 | 形态 |
|---|---|
| 斩击 | 月牙弧 |
| 突刺 | 细长光束 |
| 命中 | 核心闪点 + 冲击环（1.3px 发丝）+ 墨点 |
| 范围爆发 | 双层扩散环 + 核心闪光 |
| 光束 | 粗束 + 细芯叠加 |
| 法阵 | 中空法环（蓄力半径随 72px 格收缩至 36） |
| 治疗 | 向上生长的波纹 + 上浮粒子 |
| 印记 | 收缩的**黛环**（夜蓝，禁紫） |

发光纪律：ADD 发光只属于暴击、处决与天命之印。

### 7.3 飘字分级（`DamageText.ts`，字体 FONT.num）

| 类型 | 字号 | 颜色 | 动效 |
|---|---|---|---|
| 普攻 | 20px | 宣纸白 | 上浮 34px |
| 暴击 | 32px | 朱砂亮 | 冲击缩放 + ADD 辉光 + 抖动 |
| 技能 | 26px | 夜蓝亮 | 上浮 40px |
| 真伤 | 26px | 米金亮 | 上浮 42px |
| 治疗 | 22px | 玉青亮 | 上浮 40px |
| 护盾 | 20px | 月白亮 | 上浮 34px |
| 处决 | 36px | 米金光 | 最大冲击 + ADD 辉光 |
| 灼烧 | 16px | 朱砂光 | 轻微上浮 |

### 7.4 震动分级（累加制，边沿触发）

0.12（普击）→ 0.2（暴击）→ 0.35（技能）→ 0.7（大招）→ 1.4（处决/落印）；
`shake(min(320, 90+acc·90) ms, min(0.012, 0.0022·acc))`。

## 八、场景与棋盘（大漆盘）

### 8.1 大漆盘 —— 准备与战斗共用同一张盘

尺寸 **CELL 72 × 8 + 边 32×2 = 640**（样稿 `min(62vh,46vw)` 的落地值），
1920×1080 正中（`layout.ts BOARD_X/BOARD_Y`）。准备与战斗共用 `lacquerBoard` /
`lacquerGrid` 两张烘焙纹理，两处永不走样。

构成（自下而上）：

```
盘体（夜墨底 #08111b @ 0.95）
  → 鎏金框（外细 1px @0.5 + 内 1px @0.16 + 四角 16px 角饰）
  → 阵营微染（敌朱/我玉 @ 0.045）
  → 虚线中线（米金点划）
  → 星位四点 + 天元（围棋语汇，交叉点上点墨）
  → 盘心微光（暗色 glow 包浆）
  → 宣纸底纹（雾青 tint，备战 0.22 / 战斗 0.14）
  → 格线层（深浅交替 + 发丝描边 + 四角刻痕；入场次第淡入 460ms）
  → 悬停/标记高亮（实时 Graphics）
```

准备阶段：全 8 行可见；上半 4 行加敌营纱幕（`INK.950 @ 0.34`，仅染色，
放置规则仍由 `canPlace` 在数据层裁决）。备战席 9×64px 细条对齐格线宽。

### 8.2 阶段氛围差异

| 阶段 | 纸纹 | 粒子 |
|---|---|---|
| 备战 | 0.22 | 灵尘（月白/玉青上浮） |

## 九、UI 规范（夜宴编排）

### 9.1 设计 token

| Token | 值 |
|---|---|
| 圆角 `RADIUS` | **0**（直角体系，`main.ts` 接管 Graphics 全局生效） |
| 间距网格 `GRID` | **4** |
| 按钮高度 | 32–46（描边式） |

### 9.2 统一语言

- **直角界格**：全项目禁圆角；四角 9px 鎏金短线（`cornerTicks`）是圆角的替代品。
- **面板**：半透漆底（`INK.800 @ 0.82`）+ 顶部 1.5px 强调线 + 1px 外墨线 + 米金发丝内线。
- **按钮（描边式）**：没有实心色块——漆底、1px 金线、悬停提亮。三 variant：
  ghost（墨底淡金线）/ primary（金染底 + 米金字）/ danger（朱砂线 + 朱砂亮字）。
  悬停：金亮边 + 微金染（非发光）；按下 scale 0.96 / 70ms yoyo。
- **投影**：禁模糊阴影，一律双层描边（外 `INK.500`、内亮线 `PAPER.100 @ 0.05`）。
- **数值条**：直角底槽 → 填充 → 顶部 32% 高光 → 描边；掉血白色残影条（追速 0.05/帧）。
- **纸面颗粒**：全屏覆层（DOM 背景已含颗粒；Phaser 层 `tex_grain` 2% 共用）。
- **空态有文**：「对局伊始，万象未动」「首战未启，静候鼓角」。

### 9.4 朱文印章白名单（写死，仅 3 处）

### 9.5 天命之印（三星五费专属，样稿制式）

### 9.6 动效规范

任何状态变化都有 200~400ms 过渡：面板 320ms `Quad.easeOut`；按钮 70ms yoyo；
数值条每帧 14% 追赶；残影条 5%；卡片悬停位移 320ms；nav 金线 scaleX 展开 260ms。

### 9.7 适配

设计分辨率 **1920×1080**，`Scale.FIT + CENTER_BOTH`，缩放不错位不裁切；画布透明叠于夜色背景。

**DPR 底座**（`render/view/viewScale.ts`）：画布物理缓冲 = 1920×1080 × K（K = clamp(devicePixelRatio, 1, 2)），
各场景相机 `zoom = K` 并 `centerOn(W/2, H/2)` 钉住取景锚点 —— 逻辑坐标与 CSS 尺寸
均与旧 1× 缓冲完全一致，1 逻辑 px 恰落 1 设备像素，高分屏 / 系统缩放屏整屏发糊归零。
K=1 时逐字节等同旧渲染。文字 `resolution:2`、棋子原生分辨率烘焙在此底座上 1:1 落地。

**竖屏卷轴布局（已立项分级）**：
- 前置工程：动态逻辑分辨率——`layout.ts` 的 W/H 与分区坐标需从常量改为模式化导出，
  场景需监听 orientation 变化重建 HUD（所有 builder 已从 layout.ts 取坐标，改造面可控）；
- **P1 最小可用**：aspect < 1 时显示"横屏体验更佳"引导，游戏照常 FIT 运行（不阻断）；
- **P2 卷轴纵览**：竖屏第二布局集（1080×1920 逻辑稿）：大漆盘居中不变，顶栏收为顶部抽屉、
  羁绊/敌情收为左右滑出抽屉、牌铺纵排、字号走有效字号政策、触控热区 ≥44px；
- **P3 触控专项**：拖拽拾取阈值、长按详情、双指缩放盘面。

### 9.8 羁绊徽章（小篆 · 金线 · 几何回归）

徽章 = 篆字 + 金线，一图一态烘焙（`traitIcons`），运行期零绘制命令：

| 状态 | 环 | 字 |
|---|---|---|
| 未激活 | 单灰环 r16（INK 描边 α0.55） | 灰篆字（PAPER[300]） |
| 激活 1 档 | 一圈金线（GILT.base r16） | 纸白篆字（PAPER[100]）+ 极淡金雾 |
| 激活 2 档 | 两圈金线（r16 + r13.5） | 同上 |
| 激活 3 档 | 三圈金线（r16 / r14.75 / r13.5） | 同上 |

- 篆字 14px 按**实测墨迹框**居中（圆内唯一元素）；计数 10px mono 在环右侧外（DX 21，origin 0,0.5），与环右净距 ≥4px；
- 环组收在 r16~13.5，不侵占字区；三档羁绊（墨门/兵家/武将/护卫/方士）第三级三圈顺延；
- **档位色**（`TRAIT_TIER_COLOR_HEX`，唯一真源 `palette.ts`）：一档古铜 `0x9a7d5e` / 二档暖银 `0xb9b3a4` /
  三档米金 `0xe3cfa0` / 四档胭脂 `0xcf9bae`——左轨计数、羁绊全览标头、棋盘悬停笺、图鉴阶条与**交战菱形标记**
  （`BattleScene.ts` 悬停笺/菱形）共用同一组值；改动必须五处同步（grep `TRAIT_TIER_COLOR_HEX` 核对全部引用），
  禁止单场景点改导致阶色漂移；
- 计数随局变动，由调用处 Text 绘制（`resolution:2`），不烘焙；
- 运行期只把**场上有子**（count>0）的羁绊挂上轨，无子羁绊不占位；
- 轨几何（pitch 44、视口 76×660 完整收纳环右计数、不越记事栏）与计分板列位、悬停笺高度全部出自
  `render/view/hudLayout.ts` 纯函数，`tests/hud-layout.test.ts` 钉死遮挡不变量 ——
  任何让文字出圈、压条、越栏的改动在 `npm test` 就地报警。

## 十、音频语言

- **音阶**：五声音阶（宫商角徵羽），根音 C3 = 130.81Hz。
- **BGM 三态**：备战（8 小节 A-A'-B-A 室内乐，C→G→E→C 五声根音进行，双声部拨弦对答 + B 段加花，swing 0.018，哑光卷积混响）／交战（鼓组 kick/snare/hat 分层 + 行进低声 + 动机 call-response，锯齿经 1100Hz 低通压暗）／决赛（ghost kick 加密 + 55→44Hz 低频涌动 + 最末小节 tutti 齐奏锚点）。
- **音色纪律**：全部 saw 必经低通（580~2100Hz），Reverb 前 2.8k 低通，金色仅在三星/胜利以三角+正弦谐波点缀；禁亮黄/荧光/紫染色。
- **音效拨弦**（`playPluck`）：三角波根音 + 二/三倍频泛音，用于开战（徵 196Hz）与
  天命之印落印（宫 130.8Hz）。
- **三条总线**：BGM / SFX / UI 独立音量；BGM 共享卷积混响（1.8s 指数衰减，哑光）；音画同步——攻击音在前摇结束时触发； mood 切换交叉淡入淡出、小节对齐、后台 `suspend/resync` 不丢拍。
