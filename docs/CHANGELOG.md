## [1.2.1] - 2026-08-30 · 输入命中区整体偏移修复（点击不灵敏的真根因）

### 修复

- **容器命中区偏移半个身位**：Phaser 的输入命中测试会把局部坐标加上 `displayOrigin` 再做矩形包含，而 Container 的 `displayOrigin` 恒为「`setSize` 尺寸的一半」——等于要求命中矩形以容器中心锚定。本工程所有容器（Button / ShopCard / ItemChip / 奇遇卡）的子对象从 (0,0) 左上布局、命中矩形按左上锚定书写，两个口径叠加后：**按键只有左上一半可点，右下的点击静默丢失，悬停高亮同样只亮左上象限**——即「点击不灵敏、偶尔才反应；鼠标划过按键无悬停反馈」的全部来源。修法为在启动咽喉（`main.ts`，与圆角接管/文字 2× 分辨率同模式）把 `Container.prototype` 的 `displayOriginX/Y` 归零，使命中测试回到左上锚定口径，一处声明处处生效。
- 波及面：全部按键（主菜单/对局/面板）、商店卡购买、器匣装备格悬停（F2 悬停提示卡此前实际只在左上象限触发）。遮罩（Graphics，displayOrigin 本就为 0）、Zone（显式 origin 0）、未 `setSize` 的容器不受影响。

### 验收数据

- 事件级追踪坐实（`gameobjectdown` 在按键右下象限零触发 → 修复后 down+up 双命中，含极右下角）；商店卡右下象限购买实测生效；扫过按键悬停全键面触发；帧时间 p95 5.2ms 无卡顿（排除掉帧假说）；typecheck ✓ / 158 测试全绿 / `__qa` 零报错。
