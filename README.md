# 百战天元 · TIAN YUAN

> 天地初分，墨与纸未判。有神将、荒兽、妖灵、鬼差共弈一局，胜者执笔，重写山河。

一款在浏览器里运行的单机自走棋（Phaser 3 + TypeScript + Vite）：八人同场，你与七名 AI 诸侯各执一族。64 名棋子、17 条羁绊（10 地域＋7 职业），8 种组件两两合成 36 件成品装备；墨兽轮供给装备，奇遇轮发放六类恩赐，单局约 25–40 分钟。三星五费携带「天命护持」，是值得围绕构筑的终局面额——玩法、数值与平衡断面的唯一出处是 [docs/DESIGN.md](./docs/DESIGN.md)。

视觉与音效多为程序化生成：纸纹、颗粒、装备图标与全部打击音不占包体；入库资产为 64 张 AI 棋子立绘、羁绊小篆字库（seal.woff2）与四曲 CC0 典藏音乐（设置中可关闭，回落程序化合音）。视觉方向「夜宴 · 幽冥水墨」——夜蓝为底、米金为面、朱砂是唯一热色，规范见 [docs/ART_BIBLE.md](./docs/ART_BIBLE.md)。版本记录见 [docs/CHANGELOG.md](./docs/CHANGELOG.md)，版本号以 `src/version.ts`、`package.json` 与 CHANGELOG 顶部三处一致为准。

## 运行与门禁

需要 Node ≥ 22.5（`.nvmrc` 已固定，CI 同源读取；`start.bat` / `start.sh` 在入口探测 `node:sqlite`，旧 Node 会得到明确指引而不是难懂的原生模块报错）。

```bash
npm ci          # 按锁文件安装依赖
npm run dev     # 开发服务器 → http://localhost:5199
npm test        # 核心行为测试
npm run build   # 类型检查 + 生产构建 → dist/
npm run qa      # 交付门禁：类型 + 架构边界 + 测试 + 构建
npm run balance -- selftest  # 平衡门禁五关：数据/确定性/CRN/进程池一致/先手公平
```

Windows 双击 `start.bat`（子命令 `stop` / `status` / `restart`）；Git Bash 用 `start.sh`。脚本自动处理端口占用与退出释放。

## 操作（行为即契约）

| 动作 | 方式与保证 |
|---|---|
| 买入 / 上阵 | 点商店卡买入，拖上棋盘；`1–5`（含小键盘）直购对应卡位；同名三张自动合成升星（含跨场上/备战席与级联），合成日志逐条落盘；同名棋子可多张上场，羁绊按唯一棋子计数；拖拽落点实时染金/红边并说明原因 |
| 刷新 / 布阵 / 升级 / 开战 | `D` 刷新，`E` 一键布阵（先保 2 前排与羁绊覆盖，再按战力补同名），`F` 买经验，`空格` 准备完毕（备战无倒计时，手动开战）；全部浮层打开时，键盘、点按与悬停三路统一让路，遮罩下不会误触快捷键 |
| 撤销 | `Ctrl+Z` 或按钮，准备阶段内任意操作一步回退——棋盘、备战席、等级/经验、金币、商店、器匣、卡池、奇遇恩赐与随机流游标的完整快照（最多 30 步），撤销后重摇与被撤销那次逐位一致 |
| 装备 | 组件拖到棋子身上或器匣内另一组件上即合成；单棋子上限 3 件；主动卸装严守器匣容量、放不下整体拒绝并说明原因，成品拆回两组件；系统回收路径（卖出/淘汰/合成吃子）守恒优先；器匣溢出自动分页，页码控件仅在确有溢出时出现 |
| 卖出 | 拖到朱印「售」区，或点选棋子后经详情卡出售；2★ / 3★ 需二次确认；返还按费用×星级（1★=费、2★=3×费−1、3★=9×费−1），卡按星级拆张回池 |
| 羁绊 | 左轨徽章悬停看当前档效果，点击钉住成员名单卡（拥有/上阵情况金框高亮，随买卖原位刷新）；轨内可滚动，滚出视口的徽章不再响应悬停与点选（热区与所见一致）；图鉴羁绊册同源展开 |
| 侦查 | nav「阵容」直接查看本轮对手（备战期配对已生成；墨兽轮提示无可侦；墨影轮侦查出局阵容快照） |
| 一键装备 | 按「放大核心」原则自动配装；买入自动上场可在设置中关闭 |

存档与偏好在玩家本机浏览器：普通对局与每日挑战分键存取、互不覆盖；损坏或版本漂移的载荷在读档入口清洗（坏键/坏格不入对局，含墨影快照与墨兽阵容）并明示，写盘失败（如配额满）当场提示；音量、静音与典藏音乐开关持久化，主菜单起播即按设定音量，切换开关不中断音乐；本回合配对随档持久化，备战期存读档不重掷本轮对手。每日挑战以当日日期派生种子，全员同题。音乐在窗口失焦时自动静音、回前台恢复；授权曲目不可用时自动回落程序化合音。

## 打包分发

`npm run release` 产出三样到 `release/`：

| 产物 | 用法 |
|---|---|
| `百战天元.html` | 单文件，双击即玩。四曲音乐内联，无任何外链；微信、U 盘、邮件直发，接收方零安装 |
| `dist-web/` | 静态托管：整体上传任意静态服务器或内网分享 |
| `百战天元-<版本>-web.zip` | 上述两者 + 使用说明 + 第三方授权清单，分发归档 |

发布脚本在构建前校验：工作区干净（zip 必须对应唯一 commit）、版本三处一致、依赖与资源审计、双形态构建、外链扫描与原子替换。发布流程与回退规则见 [docs/VERSIONING.md](./docs/VERSIONING.md)。
