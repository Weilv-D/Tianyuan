# 百战天元 · TIAN YUAN

> 天地初分，墨与纸未判。有神将、荒兽、妖灵、鬼差共弈一局，胜者执笔，重写山河。

一款在浏览器里运行的单机自走棋：八人同场，你与七名 AI 诸侯各执一族。
64 名棋子、17 条羁绊，装备由 8 种组件两两合成 36 件成品；第 1 / 7 / 13 / 19 / 25 回合
五场墨兽轮供给装备，第 4 / 10 / 16 回合三次奇遇恩赐，单局约 25–40 分钟。
三星五费携带「天命护持」，是值得围绕构筑的终局面额。

技术栈 Phaser 3 + TypeScript + Vite。视觉与音效多为程序化生成：纸纹、颗粒、
装备图标与全部打击音不占包体；入库资产为 64 张 AI 生成的棋子立绘、羁绊小篆
字库与四曲 CC0 典藏音乐（可在设置中关闭，回落程序化合音）。视觉方向
「夜宴 · 幽冥水墨」——夜蓝为底、朱砂点睛。

## 运行

需要 Node ≥ 22.5（`.nvmrc` 已固定）。

```bash
npm ci          # 按锁文件安装依赖
npm run dev     # 开发服务器 → http://localhost:5199
npm test        # 核心行为测试
npm run build   # 类型检查 + 生产构建 → dist/
npm run qa      # 交付门禁：类型 + 架构边界 + 测试 + 构建
```

Windows 双击 `start.bat`（子命令 `stop` / `status` / `restart`）；Git Bash 用
`start.sh`。脚本自动处理端口占用与退出释放。

## 操作

| 动作 | 方式 |
|---|---|
| 买入 / 上阵 | 点商店卡买入，拖上棋盘；`1–5`（含小键盘）直购对应卡位；同名三张自动合成升星；同名棋子可多张上场（羁绊按唯一棋子计数） |
| 刷新 / 布阵 / 升级 / 开战 | `D` 刷新商店，`E` 一键布阵，`F` 买经验，`空格` 准备完毕；设置、成员卡、侦查等浮层打开时，键盘与点按让路 |
| 撤销 | `Ctrl+Z` 或按钮，准备阶段内任意操作一步回退——完整状态快照（含随机游标），撤销后重摇与被撤销那次逐位一致 |
| 装备 | 组件拖到棋子身上或器匣内另一组件上即合成；主动卸装严守器匣容量，放不下整体拒绝并说明原因 |
| 卖出 | 拖到朱印「售」区，或点选棋子后经详情卡出售；2★ / 3★ 需二次确认 |
| 羁绊 | 左轨徽章悬停看当前档效果，点击钉住成员名单卡（该族全部棋子的拥有情况）；轨内可滚动，计数随买卖原位刷新 |
| 一键装备 | 按「放大核心」的原则自动配装 |

## 打包分发

`npm run release` 产出三样到 `release/`：

| 产物 | 用法 |
|---|---|
| `百战天元.html` | 单文件，双击即玩。四曲音乐内联，无任何外链；微信、U 盘、邮件直发，接收方零安装 |
| `dist-web/` | 静态托管：整体上传任意静态服务器或内网分享 |
| `百战天元-<版本>-web.zip` | 上述两者 + 使用说明 + 第三方授权清单，分发归档 |

存档保存在玩家本机浏览器：普通对局与每日挑战分键存取、互不覆盖；损坏或过期的
存档键在读档时自动清理；写盘失败（如配额满）会当场提示。音乐在窗口失焦时自动
静音，回到前台恢复。

## 架构

```
src/
├── core/    战斗内核：无头、确定、30Hz 固定步长
├── data/    棋子（64）· 羁绊（17）· 装备（44）· 调参表
├── game/    对局层：经济、卡池、AI、奇遇、存档、撤销、回放
├── render/  表现层：场景、棋盘、特效、界面与输入
├── ui/      界面组件
└── audio/ + music/  程序化合音与 CC0 曲目调度
```

三条底线：

1. **内核无头** —— 战斗内核不接触渲染、DOM 与时间 API，平衡模拟与实机跑同一份代码；
2. **完全确定** —— 同一种子同一输入，必得逐字节一致的事件流，回放与测试都依赖它；
3. **资源守恒** —— 卡池买卖回流、装备拆还、撤销快照在任何路径下都不产生或吞没资产。

分层依赖由 `npm run check:boundaries` 强制检查。

## 平衡工具链

数值平衡走无头批量模拟：`npm run balance -- matrix`（对拍矩阵）、`sweep`（参数扫描）、
`items`（装备边际）、`match`（整局经济）等，完整命令见 [balance/README.md](./balance/README.md)。
模拟数据落在 git 忽略的工件库，用 `trend` 跨版本对照断面；当前平衡断面与克制关系
记录在 [docs/DESIGN.md](./docs/DESIGN.md)。

## 视觉方向

「夜宴 · 幽冥水墨」：夜蓝墨底、米金宣面、朱砂是唯一热色；楷 / 宋 / mono 三线排版、
直角界格、朱文印章表达不可逆操作；64 张 AI 立绘原生分辨率烘焙，星级银 / 金描边，
羁绊徽章为小篆单字加金线档位。完整色板、字体与动效规范见
[docs/ART_BIBLE.md](./docs/ART_BIBLE.md)。适配桌面 16:9（1920×1080 设计分辨率等比缩放）。
