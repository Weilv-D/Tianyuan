# 百战天元 · TIAN YUAN

> 天地初分，墨与纸未判。有神将、荒兽、妖灵、鬼差共弈一局，胜者执笔，重写山河。

一款在浏览器里运行的单机自走棋（Phaser 3 + TypeScript + Vite）：八人同场，你与七名 AI 诸侯各执一族。64 名棋子、17 条羁绊（10 地域＋7 职业），装备由 8 种组件两两合成 36 件成品（全表 44 件）；第 1 / 7 / 13 / 19 / 25 回合五场墨兽轮供给装备，第 4 / 10 / 16 回合三次奇遇恩赐（金币 / 经验 / 组件 / 成品 / 顿悟 / 援军六类），单局约 25–40 分钟（30 回合左右，110 血开局、后期伤害曲线放缓）。三星五费携带「天命护持」（生命×2.0、攻击法强×2.0、技能×1.25、20% 全能吸血、35% 开战护盾、免疫控制），是值得围绕构筑的终局面额；三星四费另有「登峰」小乘区（×1.15）作为便宜一档的可靠终局。

当前版本 1.16.6（`src/version.ts` 与 `package.json` 同步，落款与分发以此为准）。视觉与音效多为程序化生成：纸纹、颗粒、装备图标与全部打击音不占包体；入库资产为 64 张 AI 棋子立绘、羁绊小篆字库（seal.woff2）与四曲 CC0 典藏音乐（设置中可关闭，回落程序化合音）。视觉方向「夜宴 · 幽冥水墨」——夜蓝为底、米金为面、朱砂是唯一热色。

## 运行与门禁

需要 Node ≥ 22.5（`.nvmrc` 已固定）。

```bash
npm ci          # 按锁文件安装依赖
npm run dev     # 开发服务器 → http://localhost:5199
npm test        # 核心行为测试（160 项全绿）
npm run build   # 类型检查 + 生产构建 → dist/
npm run qa      # 交付门禁：类型 + 架构边界（77 文件） + 测试 + 构建
npm run balance -- selftest  # 平衡门禁五关：数据/确定性/CRN/进程池一致/先手公平
```

Windows 双击 `start.bat`（子命令 `stop` / `status` / `restart`）；Git Bash 用 `start.sh`。脚本自动处理端口占用与退出释放。生产构建输出 Phaser 分包与内联资源，`npm run release` 另产出单文件与托管两形态（见下）。

## 操作（行为即契约）

| 动作 | 方式与保证 |
|---|---|
| 买入 / 上阵 | 点商店卡买入，拖上棋盘；`1–5`（含小键盘）直购对应卡位；同名三张自动合成升星（含跨场上/备战席与级联），合成日志逐条落盘；同名棋子可多张上场，羁绊按唯一棋子计数；人口（=等级，上限 9）满时备战席移入空格被拒、被占格仍可交换，拖拽落点实时染金/红边并说明原因 |
| 刷新 / 布阵 / 升级 / 开战 | `D` 刷新（2 金），`E` 一键布阵（先保 2 前排与羁绊覆盖，再按战力补同名，拥挤不覆写不丢子），`F` 买经验（4 金=4 经验），`空格` 准备完毕（备战无倒计时，手动开战）；设置、成员卡、侦查等浮层打开时键盘与点按统一让路 |
| 撤销 | `Ctrl+Z` 或按钮，准备阶段内任意操作一步回退 —— 棋盘 32 格＋备战席 9 格＋等级/经验＋金币＋商店＋器匣＋卡池＋奇遇 offer＋随机游标的完整快照（最多 30 步），撤销后重摇与被撤销那次逐位一致 |
| 装备 | 组件拖到棋子身上或器匣内另一组件上即合成；单棋子上限 3 件；主动卸装（单件/整件）严守器匣 10 格、放不下整体拒绝并说明原因，成品拆回两组件；卖出/合成吃子/淘汰等系统回收允许溢出（守恒优先，超格部分不可见但仍入存档） |
| 卖出 | 拖到朱印「售」区，或点选棋子后经详情卡出售；2★ / 3★ 需二次确认；返还按费用×星级（1★=费，2★=3×费−1，3★=9×费−1），卡按星级拆张回池 |
| 羁绊 | 左轨徽章悬停看当前档效果，点击钉住成员名单卡（该族全棋子的拥有/上阵情况，金框高亮，计数随买卖原位刷新）；轨内可滚动；图鉴羁绊册同源展开 |
| 一键装备 | 按「放大核心」原则自动配装；买入自动上场可在设置中关闭（同名已在场/人口满/开关关闭时不上） |

棋盘与备战席长度恒为 32 / 9：任何移动、买卖、布阵与读档路径都不撑长数组；满盘时推荐位返回无位而不是覆写首格。

## 存档、日挑战与音频

存档在玩家本机浏览器：普通对局与每日挑战分键存取（`inkarena.save.v3` / `.daily`，旧 `v2` 自动迁移）、互不覆盖；损坏、截断或版本漂移的载荷在读档时判空并清理坏键（含卡池逐键清洗、深度数据语义断言与 board/bench 长度收敛），写盘失败（如配额满）当场提示。每日挑战以当日日期派生种子，全员同题。音乐在窗口失焦时自动静音、回前台恢复；授权曲目不可用时自动回落程序化合音。

## 架构（77 个 src 文件）

```
src/
├── core/    战斗内核：无头、确定、30Hz 固定步长（Battle/Rng/技能/羁绊/装备行为）
├── data/    棋子（64）· 羁绊（17）· 装备（44：8 组件＋36 成品）· 调参表
├── game/    对局层：经济、卡池、AI 五原型、奇遇、存档、撤销、回放、每日挑战
├── render/  表现层：场景（菜单/对局/战斗/结算/图鉴）、棋盘、特效、输入、HUD
├── ui/      界面组件（卡片/悬浮详情/设置/提示）
└── audio/ + music/  程序化合音三总线与 CC0 曲目调度
```

三条底线（由 `npm run check:boundaries` 强制检查，覆盖计数断言保证新文件不脱检）：

1. **内核无头** —— `core / data` 不接触渲染、DOM、时间与随机源（仅 `game/save` 可用时间），平衡模拟与实机跑同一份代码；
2. **完全确定** —— 同一种子同一输入必得逐字节一致的事件流（目标分单位/落点双通道同源，加权统一严格小于口径），回放与测试都依赖它；
3. **资源守恒** —— 卡池买卖回流、装备拆还、撤销快照在任何路径下都不产生或吞没资产（含满席溢出槽收敛与合并回滚）。

## 平衡工具链

数值平衡走无头批量模拟，`npm run balance -- <command>`（与游戏分离，`src` 不引用 `balance/`）。支持共 19 项专业指令：
- 核心矩阵与扫参：`matrix`（对拍矩阵断面）、`sweep`（参数扫描）、`ab`（定向 CRN 配对）、`bench`（基准测试）、`selftest`（五关自动化门禁）、`trend`（跨版本趋势对照）
- 维度边际：`traits`（羁绊边际）、`items`（装备边际＋合成/堆叠曲线）、`units`（单位战力榜）
- 系统流转与专项：`match`（整局经济）、`shop`（出货与刷店成本）、`legend`（天命专项）、`beast`（墨兽自检）、`audit`（全域审查）、`roster`（阵容全览）、`gold`（经济流动）、`diag`（内核诊断）、`probe`（边界探测）、`bigorigins`（大地域专项）

模拟数据落在 git 忽略的 SQLite 工件库；当前平衡断面、克制关系与验收快照记录在 [docs/DESIGN.md](./docs/DESIGN.md)（§十二/§十四）。

## 打包分发

`npm run release` 产出三样到 `release/`：

| 产物 | 用法 |
|---|---|
| `百战天元.html` | 单文件，双击即玩。四曲音乐内联，无任何外链；微信、U 盘、邮件直发，接收方零安装 |
| `dist-web/` | 静态托管：整体上传任意静态服务器或内网分享 |
| `百战天元-<版本>-web.zip` | 上述两者 + 使用说明 + 第三方授权清单，分发归档 |

发布脚本校验版本三处一致（`src/version.ts` / `package.json` / `CHANGELOG` 顶部）、依赖与资源审计、外链扫描与原子替换。
